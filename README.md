# jupiters 6 største måner:

- Ganymedes: Solsystemets største måne. Den er større enn planeten Merkur.
- Callisto: Den nest største, tungt kratersatt og svært gammel overflate.
- Io: Den tredje største, kjent for ekstrem vulkansk aktivitet.
- Europa: Den fjerde største, dekket av is med et flytende hav under.
- Amalthea: En liten, uregelmessig formet og svært rød innre måne.
- Himalia: Den største av Jupiters ytre, uregelmessige måner.
